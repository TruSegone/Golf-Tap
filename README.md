# Golf Tap

Golf Tap is a bright, one-hole arcade golf game built in Java with libGDX. Line up each shot, hold to charge its power, avoid sand and water, and sink the ball in eight strokes or fewer.

## Play in a browser

Reviewers can use the playable browser preview at [trusegone.github.io/Golf-Tap](https://trusegone.github.io/Golf-Tap/). It is deployed automatically through GitHub Pages after changes are pushed to `main`.

## Run the desktop game

Run `gradlew.bat run` on Windows (or `./gradlew run` elsewhere).

Controls: move the mouse to aim; hold and release left mouse or Space to charge and hit. `R` restarts the hole and `Esc` returns to the menu.
